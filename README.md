# RAW Management для Windows

Оболочка окна для веб-приложения RAW Management: трей, уведомления Windows, автозапуск,
автообновление через релизы этого репозитория.

Скачать установщик: раздел **Releases** справа → `RAW-Management-Setup-x.y.z.exe`.

Новая версия: поднять `version` в `package.json` и запушить тег `vX.Y.Z` — GitHub Actions соберёт
установщик и опубликует релиз, установленные приложения обновятся сами.
